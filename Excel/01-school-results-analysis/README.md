# School Results Analysis

A practical Excel project for analysing learner performance using school assessment data.

## Skills Practised

- Data entry and organization
- Excel formulas
- Totals and averages
- Ranking
- Sorting and filtering
- Conditional formatting
- Excel Tables
- PivotTables
- Charts
- Basic data analysis

## Objective

To use Excel to transform school assessment data into useful information that can support teaching, learning, and performance monitoring.

## Project Status

Learning and development project.

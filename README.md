# School Tech Projects

A collection of practical technology projects developed through school learning, the Coding Club, and hands-on digital skills activities.

## Areas Covered

- 💻 Coding and Programming
- 🤖 Robotics and STEM
- 📊 Microsoft Excel and Data Analysis
- 📈 Power BI and Data Visualization
- 🗄️ SQL and Databases
- 🌐 Web Development
- 🤖 Artificial Intelligence and Digital Tools

## Purpose

This repository documents practical projects, exercises, experiments, and learning activities designed to develop digital skills, problem-solving, creativity, and data literacy.

## Projects

Projects will be added progressively as learners and the Coding Club explore new technologies and complete practical activities.

## Learning Approach

**Learn → Build → Test → Improve → Share**
